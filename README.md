# 1학년 11반 반티 주문 확인 (엑셀 직접 연동 버전)

이 버전은 GitHub 저장소에 올린 `2026_1-11반_반티주문서.xlsx`를 서버에서 직접 읽어 학생별 조회 API를 제공합니다.

## 실행
```bash
npm install
npm start
```

기본 주소: `http://localhost:3000`

## 데이터 소스
- 기본 파일: 루트의 `2026_1-11반_반티주문서.xlsx`
- 변경 시 환경변수 사용 가능: `ORDER_XLSX_FILE=/path/to/file.xlsx npm start`

## 필수 시트
- `2_상의 개별내역`
- `3_하의 개별내역`
- `4_학생별 비용`
- `5_주의사항` (선택)

## API
- `GET /api/order?studentId=11101`

## 보안 주의
- 프론트엔드에 전체 명단을 넣지 않고 서버에서 단건 조회 후 반환합니다.
- MVP는 학번 단독 조회 방식이므로 향후 2차 확인값(이름/개인코드) 추가를 권장합니다.
