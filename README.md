# 반티 주문 조회 앱 (재설계 버전)

## 핵심 변경
- Google Apps Script 의존 없이, 저장소의 `2026_1-11반_반티주문서.xlsx`를 서버가 직접 읽습니다.
- 서버가 시작 실패하지 않고, 데이터 로딩 상태를 `/api/health`로 확인할 수 있습니다.
- 파일 누락/시트 누락 시 원인을 API 메시지로 바로 확인할 수 있습니다.

## 실행
```bash
npm install
npm start
```

기본 주소: `http://localhost:3000`

## 필수 파일/시트
- 루트 파일명: `2026_1-11반_반티주문서.xlsx`
- 필수 시트:
  - `2_상의 개별내역`
  - `3_하의 개별내역`
  - `4_학생별 비용`
- 선택 시트:
  - `5_주의사항`

## 진단 API
- `GET /api/health`: 로딩 성공 여부, 학생 수, 오류 원인 확인
- `POST /api/reload`: 엑셀 파일 교체 후 재로딩

## 조회 API
- `GET /api/order?studentId=11101`

## 개인정보 보호
- 클라이언트에 전체 명단을 내려보내지 않고 단건만 반환합니다.
- 현재는 학번 단독 조회(MVP)이므로 추후 2차 인증값을 권장합니다.
